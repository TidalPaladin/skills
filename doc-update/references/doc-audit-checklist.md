# Documentation Audit Checklist

Use for a broad documentation audit. Apply each check to the requested scope.

- Identify the documents and current working changes that affect their claims.
- Verify commands and material claims against code, configuration, or policy.
- Resolve conflicting instructions and link to the canonical detailed source.
- Check reference paths and examples. Execute relevant commands when authorized.
- Distinguish verified behavior from unavailable evidence or blocked checks.
- Report unresolved mismatches without claiming completion.

A typo correction needs the relevant text and context. A process change also
needs its callers, references, and validation contract.
