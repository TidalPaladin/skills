# MedCognetics Public Brand Reference

## Source Status

This reference records visual properties observed on public MedCognetics web
pages on July 30, 2026. It is not an official brand manual.

Public sources:

- [MedCognetics official website](https://www.medcognetics.com/)
- [MedCognetics privacy policy and terms of service](https://www.medcognetics.com/privacy)

The official website provides the observed colors and web typography. The terms
state that the MedCognetics name, logo, custom graphics, and trade dress require
prior permission for use. Public visibility does not grant redistribution
rights.

Use a newer authorized company guide when the user supplies one. Keep that
guide and any derived private details out of this public skill unless the user
confirms that they are approved for public distribution.

## Authored Format Recommendations

The following rules are practical recommendations for consistent output. They
are not published MedCognetics standards.

### Common Brand Application

- Use only an authorized official logo asset. Do not bundle, download, trace,
  or recreate the logo from the public observations.
- Use primary blue for large headings, rules, icons, and diagram emphasis.
- Use charcoal or dark gray for body text. Check contrast before using blue for
  small text.
- Reserve light blues and the light neutral for fills, separators, or secondary
  diagram elements.
- Use Poppins and Open Sans when they are available and their licenses fit the
  target workflow. Do not bundle font files in this skill.
- Use Arial as the portable PowerPoint and Office fallback:

  | Role | Preferred | Portable fallback |
  | --- | --- | --- |
  | Display and headings | Poppins | Arial Bold |
  | Body, labels, and captions | Open Sans | Arial |

### Presentations

- Use a 16:9 canvas, normally 13.333 by 7.5 inches.
- Use a white background with blue headings and charcoal body text.
- Set primary slide titles around 28 to 32 points.
- Set body text around 14 to 18 points. Increase sizes for large rooms or
  projected presentations.
- Keep one main message per slide and use whitespace to separate sections.
- Place an authorized logo consistently, such as at the upper right on content
  slides and in a prominent position on cover or closing slides.
- Use blue and gray for most diagrams. Add another color only when it carries a
  defined category or status.
- Keep footers small and quiet. Include a classification, owner, date, or slide
  number only when the artifact requires it.
- Prefer editable shapes and text over flattened screenshots.

### Technical and Long-Form Documents

- Use the required page size. When no standard applies, start with US Letter
  and margins near one inch.
- Use XCharter or another readable serif for long-form LaTeX body text. Use the
  public web fonts or their portable fallbacks for headings, labels, and
  diagrams when the toolchain supports them.
- Build a clear cover with title, subtitle, date, version, and prepared-by
  fields when those fields apply.
- Add revision history and a table of contents only for controlled or
  sufficiently long documents.
- Keep running headers and footers consistent. Use page numbers in long
  documents.
- Use light neutral fills and thin gray rules in tables. Keep body text dark and
  reserve blue for hierarchy or emphasis.
- Place an authorized logo on the cover or header without crowding the title or
  metadata.

### Images and Diagrams

- Use images that are public, licensed, generated for the task, or supplied for
  the authorized output.
- Do not reuse distinctive graphics from another artifact unless their license
  and destination permit it.
- Keep icon style, stroke weight, and color treatment consistent.
- Label axes, legends, units, sources, and uncertainty where relevant.
- Provide alt text or an equivalent accessible description when the format
  supports it.

## Rendering Checks

Inspect the rendered result rather than relying on source markup alone:

- confirm that fonts resolve or fall back as intended;
- inspect every page or slide for overflow, clipping, and overlap;
- verify logo proportions and sufficient surrounding space;
- confirm that small blue text remains legible;
- check that diagrams remain understandable in grayscale;
- verify that classification text matches the intended destination.
